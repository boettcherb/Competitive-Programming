USACO:
  2019-2020:
    2019 December:
      Bronze 1: Cow Gymnastics
        Techniques: Brute Force (Combination Enumeration),
          Preprocessing (Inverse Mapping)
        Complexity: O(KN^2)
        Difficulty: Easy
        Key Idea: Store each cow's position in each session so that pairwise
          ranking comparisons become O(1). Avoid repeatedly scanning rankings
          to find cow positions.
      Bronze 2: Where Am I?
        Techniques: Brute Force (Candidate Enumeration)
        Complexity: O(N^2)
        Difficulty: Easy
        Key Idea: Try every possible K and generate every K-length substring.
          Use a set to detect whether any substring occurs more than once.
      Bronze 3: Livestock Lineup
        Techniques: Brute Force (Permutation Enumeration)
        Complexity: O(8! * N * 8)
        Difficulty: Easy
        Key Idea: Enumerate all cow orderings in lexicographical order and
          output the first ordering satisfying all adjacency constraints.
      Silver 1: MooBuzz
        Techniques: Binary Search (First True)
        Complexity: O(logN)
        Difficulty: Easy
        Key Idea: For any value x, let count(x) be how many numbers <= x are
          not divisible by 3 or 5. Use binary search to find the first value
          x such that count(x) >= n
      Silver 2: Meetings
        Techniques: Sorting, Two Pointers (Sliding Window)
        Complexity: O(NlogN)
        Difficulty: Hard
        Key Idea: Treat collisions as cows passing through each other. Separate
          the cows into left-moving and right-moving, and use sorting and exit
          exit events to find T. Then, use a two-pointer method to count
          collisions by finding pairs of cows such that they are moving towards
          each other and their initial distance is <= 2T.
      Silver 3: Milk Visits
        Techniques: Graphs (Flood Fill)
        Complexity: O(N + M)
        Difficulty: Medium
        Key Idea: Use flood fill to create connected components with the same
          milk type. For each query, if the endpoints are in different
          components, the farmer will always be happy.
    2020 January:
      Bronze 1: Word Processor
        Techniques: Greedy
        Complexity: O(N)
        Difficulty: Trivial
        Key Idea: Process words from left to right. At each word, put it on
          the current line if it fits. Otherwise, start a new line.
      Bronze 2: Photoshoot
        Techniques: Brute Force (Candidate Enumeration)
        Complexity: O(N^2)
        Difficulty: Easy
        Key Idea: Try all possible values of a[0] from smallest to largest.
          Once a[0] is chosen, all other values are forced by a[i + 1] =
          b[i] - a[i]. The first valid permutation is lexicographically smallest.
      Bronze 3: Race
        Techniques: Binary Search (Last True)
        Complexity: O(NlogK)
        Difficulty: Medium
        Key Idea: For a candidate top speed s, calculate the distance required
          to accelerate to s, then decelerate to x, then remaining time
          travelled at speed s to reach total k meters travelled. Binary search
          to find max s.
      Silver 1: Berry Picking
        Techniques: Brute Force (Candidate Enumeration), Greedy
        Complexity: O(N^2 * logN)
        Difficulty: Medium
        Key Idea: Try every basket size b as the min size of Elsie's baskets.
          Greedily make as many full baskets of size b as possible. If < k
          baskets are filled, use the largest remainders for Bessie's baskets.
      Silver 2: Loan Repayment
        Techniques: Binary Search (Last True), Math
        Complexity: O(logN * sqrt(N))
        Difficulty: Medium
        Key Idea: Binary search to find X. In the check(x) function, use math
          to batch together all days with the same y value instead of
          simulating days one at a time.
      Silver 3: Wormhole Sort
        Techniques: Binary Search (Last True), Graphs (DSU)
        Complexity: O(log(10^9) * (N + M))
        Difficulty: Hard
        Key Idea: Binary search to find w, the maximum minimal wormhole width.
          For each w, use a DSU data structure to see if every cow can reach
          their sorted position using only edges with weight >= w.
    2020 February:
      Bronze 1: Triangles
        Techniques: Brute Force (Combination Enumeration)
        Complexity: O(N^3)
        Difficulty: Easy
        Key Idea: with N <= 100, we can brute force all N^3 combinations of
          3 points to find the triangle with the max area.
      Bronze 2: Breed Flip:
        Techniques: Greedy
        Complexity: O(N)
        Difficulty: Easy
        Key Idea: Each contiguous segment where A and B differ can be fixed
          with one flip. The answer is the number of segments.


Techniques:
  Preprocessing:
    Inverse Mapping:
      USACO 2019-Dec-B1: Cow Gymnastics:
        Convert the input from "list of cows in ranked order per session"
        to "ranking given cow and session" so comparisons are O(1).
  Brute Force:
    Combination Enumeration:
      USACO 2019-Dec-B1: Cow Gymnastics:
        Enumerate all pairs of n cows and compare their rankings for all
        k sessions.
      USACO 2020-Feb-B1: Triangles
        Enumerate all triplets of points to find the max-area triangle.
    Candidate Enumeration:
      USACO 2019-Dec-B2: Where Am I?:
        Try each possible K from 1 to N and test whether all K-length
        substrings are unique
      USACO 2020-Jan-B2: Photoshoot
        Try  each possible first value a[0] in increasing order. For each
        candidate, reconstruct the permutation using a[i+1] = b[i] - a[i],
        and check whether all values are unique and valid.
      USACO 2020-Jan-S1: Berry Picking:
        Try every possible value b for the size of Elsie's smallest basket.
        For each b, greedily evaluate the best possible basket allocation.
    Permutation Enumeration:
      USACO 2019-Dec-B3: Livestock Lineup:
        Start with the cows in alphabetical order and use next_permutation
        to enumerate through all 8! possible lineups. The first satisfying
        all adjacency constraints is lexicographically smallest.
  Greedy:
    USACO 2020-Jan-B1: Word Processor:
      For each word, place it on the current line if it fits. Otherwise,
      start a new line and place it there.
    USACO 2020-Jan-S1: Berry Picking:
      For a fixed basket size b, make as many full size-b baskets as possible.
      If fewer than K baskets are filled, give Bessie the largest remaining
      remainders.
    USACO 2020-Feb-B2: Mad Scientist
      Search through the two strings A and B and find contiguous segments where
      they differ. The number of flips needed is the number of segments.
  Binary Search:
    First True:
      USACO 2019-Dec-S1: MooBuzz:
        Let count(x) be how many numbers <= x are not divisible by 3 or 5.
        Find the smallest x such that count(x) >= n.
    Last True:
      USACO 2020-Jan-B3: Race:
        Binary search for the maximum top speed s. For each s, determine if
        Bessie can reach s in a valid race, and the race time in seconds.
      USACO 2020-Jan-S2: Loan Repayment:
        Binary search for the largest value X such that the loan can still be
        repaid within K days.
      USACO 2020-Jan-S3: Wormhole Sort:
        Binary search for the maximum minimal wormhole width that allows all
        cows to still be sorted.
  Two Pointers:
    Sliding Window:
      USACO 2019-Dec-S2: Meetings:
        After finding T, for each right-moving cow cR at position p, find left-
        moving cows with positions in the range (p, p + 2T]. Sliding window
        works because the left- and right-moving cow lists are sorted by position.
  Graphs:
    Connected Components / Flood Fill:
      USACO 2019-Dec-S3: Milk Visits:
        Use flood fill/dfs to find connected components with the same milk type.
        Queries can then be answered in O(1).
    Connected Components / DSU:
      USACO 2020-Jan-S3: Wormhole Sort:
        Use a DSU data structure to determine if cow i is in a connected
        component that allows it to travel to position i.
  Math:
    USACO 2020-Jan-S2: Loan Repayment:
      Quotient Batching: floor((N-G)/X) stays constant over ranges of G. Compute
      how many days this value remains constant and skip that entire block at
      once instead of simulating each day individually.
